# ЛР18. Автоматизированное тестирование: интернет-магазин (вариант 2)

Приложение «Система управления товарами и заказами» с трехуровневой
архитектурой и набором модульных, параметризованных и интеграционных тестов.

## Предметная область

- **Товар** (`Product`): название, цена, количество на складе.
- **Заказ** (`Order`) и его позиции (`OrderItem`): покупатель, товары,
  количество, стоимость.

Сценарии, проверяемые тестами:

1. создание товара;
2. создание заказа;
3. изменение количества товара;
4. расчёт стоимости заказа;
5. невозможность заказать отсутствующий товар.

## Архитектура

```
Interface (services/cli.py)
        ↓
Service (services/shop_service.py)
        ↓
Repository (repositories/sqlite_repository.py)
        ↓
SQLite
```

Бизнес-правила находятся в `ShopService`, SQL — в репозитории,
консольное меню — в `ConsoleUI`.

## Запуск

```bash
pip install -r requirements.txt
python src/main.py
```

## Тесты

```bash
pytest
```

Состав набора:

- unit-тесты моделей и сервиса (с `MagicMock` вместо репозитория);
- параметризованные проверки границ;
- интеграционные тесты сервиса с реальной SQLite (`:memory:`).

Коды ошибок предметной области: `ValidationError`, `NotFoundError`,
`InsufficientStockError`.
